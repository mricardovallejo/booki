# BooKI release notes

## v0.2.0 — Reading setup and language support
**Date:** 2026-09-06 · **Tag:** `v0.2.0`
- Separate tutor and reader profiles, with independent editors and per-session selection.
- Versioned prompt catalog plus inclusive language-support reader and tutor defaults.
- Security hardening, integration tests, frontend quality gates, and verified PostgreSQL/GCS deployment configuration.

## v0.1.0 — First deployed version
**Date:** 2026-09-03 · **Tag:** `v0.1.0`
- PDF library with page-range reading sessions, tags, quizzes, summaries, progress, and reports.
- Context-aware AI conversation by text or voice, conversational capabilities, and multiple AI providers.
- First cloud deployment on Firebase and Cloud Run, backed by Neon PostgreSQL and GCS-compatible object storage.
